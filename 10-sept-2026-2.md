## 2. Autentikasi (login gate)

| File | Fungsi |
|------|--------|
| `src/app/login/page.tsx` | Halaman login (design token VMA: sand/clay/ink) |
| `src/app/api/auth/login/route.ts` | Verifikasi kredensial + set cookie |
| `src/app/api/auth/logout/route.ts` | Hapus cookie |
| `src/proxy.ts` | Gate semua route (Next 16 menggantikan `middleware.ts`) |
| `src/lib/auth.ts` | HMAC session token + PBKDF2 password |
| `src/lib/rateLimit.ts` | Throttle per-IP + backstop global |
| `scripts/hash-password.mjs` | Generator hash password |

### Detail keamanan
- Session: cookie `HttpOnly`, `Secure`, `SameSite=strict`, HMAC-SHA256, TTL 12 jam
- Password: PBKDF2-SHA256, 210.000 iterasi, salt 16 byte, perbandingan constant-time
- Hash disimpan di env server (`VMA_AUTH_PASSWORD_HASH`), tidak pernah di client
- Rate limit per-IP: 5 gagal → lock 15 menit
- Backstop global: 15 gagal/10 menit → delay naik sampai 3,5s; 40 gagal → blok 2 menit
- `CF-Connecting-IP` diprioritaskan (Cloudflare menimpanya di setiap request)
- Semua route di balik login; API balas `401` bila tanpa session
- Tombol "Sign out" di sidebar

### Catatan deployment
- Dua bug yang ditemukan & diperbaiki saat deploy:
  1. **502**: NPM jalan di container, jadi `127.0.0.1:3100` dari sisinya
     menunjuk ke dirinya sendiri. Diperbaiki dengan network bersama + forward
     ke `vma:3000`.
  2. **Login selalu gagal**: Docker Compose meng-interpolasi `$` di `.env`,
     sehingga hash `pbkdf2$...` jadi kosong. Format hash diganti ke pemisah
     `:` (`pbkdf2:<iter>:<salt>:<hash>`).
