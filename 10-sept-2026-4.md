## 🟠 Keamanan (3)

**B1. Batas biaya `/api/chat`** — endpoint termahal justru terbuka.
- Sliding window per IP: **150 permintaan / 5 menit** (`VMA_CHAT_MAX_REQUESTS`, `VMA_CHAT_WINDOW_SECONDS`)
- Body dibaca sebagai teks dulu, ditolak `413` kalau lebih dari **1 MB** (`VMA_MAX_BODY_BYTES`)
- `400` untuk JSON rusak dan bentuk request yang tidak sesuai
- Angka bawaan sengaja longgar karena satu giliran debat memanggil endpoint berkali-kali

**B2. Sandbox iframe** — `HTMLPreview` memakai `allow-scripts allow-same-origin`. Kombinasi ini memungkinkan frame melepas atribut sandbox-nya sendiri lalu mengakses origin aplikasi, yang menyimpan API key di localStorage. Diganti ke `srcDoc` + `sandbox="allow-scripts"` (tanpa same-origin).

**B3. Celah SSRF IPv4-mapped** — parser URL menulis ulang `::ffff:127.0.0.1` menjadi `::ffff:7f00:1`, sehingga pola bertitik tidak cocok dan loopback tetap bisa dijangkau. **Ditemukan oleh test yang baru ditulis**, bukan pemeriksaan manual. Kedua bentuk (heksa dan bertitik) sekarang ditangani.

## 🟡 Keandalan (3)

**C1. Penyimpanan gagal diam-diam** — `localStorage` dibatasi ~5 MB dan semua penulisan dibungkus `catch { /* ignore */ }`. Begitu kuota penuh, pesan berhenti tersimpan **tanpa peringatan**. Sekarang: `safeSetItem()` melaporkan kegagalan, disimpan di state, ditampilkan sebagai banner dengan tombol dismiss.

**C2. Pesan yatim** — `clearMessages` hanya didefinisikan, **tidak pernah dipanggil**. Setiap sesi yang dihapus meninggalkan pesannya di `localStorage` selamanya. Sekarang hapus sesi ikut hapus pesannya.

**C3. Tidak ada error boundary** — satu error render = layar putih total. Ditambahkan `error.tsx`, `global-error.tsx`, `not-found.tsx`.

## 🟣 Aksesibilitas (4)

**D1. Kontras.** Data kontras membuktikan `ink-faint` **tidak mungkin** lolos AA sebagai teks di semua permukaan yang dipakai (butuh ~4.7:1, yang membuatnya identik dengan `ink-muted`). Jadi perannya dipisahkan:
- Teks → `ink-muted` (5.7:1), 72 penggantian
- Border/ikon → `ink-faint`, digelapkan `#9c9590` → `#8a8480` (3.7:1) agar melewati ambang 3:1 elemen non-teks
- Cincin fokus → `sand-400` (2.3:1) menjadi `sand-500`

**D2. Biaya karangan.** `TokenMeter` menampilkan estimasi dolar dari tarif `$0.002/1k` yang **tidak punya sumber**. Dihapus; token tetap ditampilkan dan ditandai sebagai estimasi.

**D3. Dead code.** 13 import/variabel tidak terpakai dihapus, dibuktikan dengan `tsc --noUnusedLocals`.

**D4. Bug rendering tambahan.** 22 referensi CSS var dengan nama salah (`var(--border)` padahal tokennya `--color-border`) — border dan warna jatuh ke nilai fallback. Diperbaiki.
