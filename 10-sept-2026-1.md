## Ringkasan Proyek

**VMA (Virtual Multi-Agent Debate)** — Aplasi web multi-agent debate dengan AI moderator, dibangun dengan Next.js 16 + React 19 + Zustand + Vercel AI SDK.

### Tech Stack
| Layer | Teknologi |
|-------|-----------|
| Framework | Next.js 16 (App Router) |
| UI | React 19, Tailwind CSS 4 |
| State | Zustand 5 (persist ke localStorage) |
| AI | Vercel AI SDK (`ai` v7), `@ai-sdk/openai`, `@ai-sdk/anthropic` |
| Storage | localStorage (state) + IndexedDB via `idb` (dokumen) |
| Language | TypeScript 7 |
| Backend opsional | Python (port 8000) — code interpreter, browser, knowledge base |

### Fitur Utama
1. **Multi-Agent Debate** — 3 default agents (Maya/Aldo/Sinta) + custom agents
2. **AI Moderator** — 3 fase: Opening → Loop Agentik → Ringkasan (decision parser JSON)
3. **BYOK** — OpenAI, Anthropic, OpenRouter, Ollama, custom endpoint
4. **Preset Modes** — Boardroom, Supportive, Learning, War Room, Custom
5. **Response Modes** — @Name, @all, auto-select (relevance scoring)
6. **Knowledge Base** — Upload dokumen per-agent (IndexedDB)
7. **Extras** — Code Interpreter, Browser View, Wikipedia Search, HTML Preview, PPT Viewer

### Design System
- **Palette**: Earth-tone (sand, clay, sage, rust) — "Anti AI Slop"
- **Font**: Inter (body) + JetBrains Mono (code)
- **Animation**: fadeUp, fadeIn, slideIn, pulse-dot
- **Zero backend dependency** untuk core functionality
